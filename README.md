# powershell-scripts
Useful PowerShell scripts I've accumulated over time

I am a helpdesk technician and aspiring sysadmin who is always trying to improve my tech skills. I've found a lot of applications for PowerShell scripting inside of my daily workflows and would like to share some of them through this repo. 

I'm going to try to make the scripts as org-agnostic as possible. Use cases will change from company to company, so consider making modifications to best fit your environment.

I have used AI (mainly Copilot) to generate a lot of the syntax for these scripts. As we know, AI is rarely perfect and frequently incorrect. In fact, fixing errors in the generated scripts has been a large part of my learning about PowerShell and its syntax. Please note any improvements on these scripts you think I can make.
